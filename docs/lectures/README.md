# Foundations lectures

Read these short lessons before the data-gathering demo. The original lecture
PDF isn't needed; page references are included only for provenance.

1. [Introduction to data science](01-intro-to-data-science.md): what data
   science delivers and when prediction is useful.
2. [Scoping a data project](02-scoping-a-project.md): turn a real decision into

3. [Working in a Jupyter notebook](03-jupyter-notebooks.md): run cells, explain
   your work, and distinguish saved results from live Python state.

Use the [setup guide](../setup.md) to launch JupyterLab for the third lesson.
Then return to the [course learning map](../../README.md#learning-map) for the
demo and exercises.
